# 05 — JavaScript dan DOM

JavaScript merupakan prasyarat penting sebelum React dan Next.js.

## Tujuan

- Memilih elemen dengan `querySelector`.
- Mendengarkan event dengan `addEventListener`.
- Mengubah teks dan class elemen.
- Memvalidasi input sederhana.

## Tugas

Selesaikan TODO di `script.js` agar penghitung belajar dapat:

1. menambah jumlah sesi;
2. mengurangi sesi tanpa pernah menjadi negatif;
3. mereset sesi ke nol;
4. menampilkan pesan motivasi saat mencapai lima sesi.

Setelah selesai, coba operasikan seluruh tombol hanya dengan keyboard.
