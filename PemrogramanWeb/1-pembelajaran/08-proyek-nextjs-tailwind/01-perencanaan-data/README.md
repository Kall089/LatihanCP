# Tahap 01 — Perencanaan Data

1. Tulis minimal 6 materi di `materials.ts`.
2. Setiap materi memiliki `slug`, `title`, `description`, `level`, dan `completed`.
3. Buat union type untuk level: `pemula | menengah | lanjut`.
4. Pastikan semua slug unik, huruf kecil, dan memakai tanda hubung.

Gunakan starter lalu jalankan TypeScript checker proyek.
