Perbedaan box-sizing

Kedua kotak berikut memiliki width: 200px, padding: 20px, dan border: 10px.

Lebar akhir: 260px

content-box

Width hanya mengukur bagian isi.

Lebar akhir: 200px

border-box

Width sudah mencakup padding dan border.

Contoh saat memakai width: 100%

Garis putus-putus menunjukkan batas wadah.

content-box
Kotak ini keluar dari wadah.
border-box
Kotak ini tetap pas di dalam wadah.
