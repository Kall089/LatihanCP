# 04 — Tailwind CSS

## Tujuan

- Memahami utility-first CSS.
- Memakai class untuk spacing, warna, tipografi, border, dan shadow.
- Menggunakan modifier `hover:`, `focus:`, `sm:`, `md:`, dan `lg:`.

## Tugas

Lengkapi atribut `class` yang bertanda TODO di `index.html`. Jangan menulis CSS manual pada latihan ini.

Target:

- halaman memiliki latar lembut dan konten terpusat;
- daftar kartu satu kolom pada ponsel dan tiga kolom pada desktop;
- tombol memiliki hover serta focus ring;
- spacing konsisten.

Latihan ini memakai Play CDN agar bisa langsung dibuka. Gunakan instalasi Tailwind melalui npm ketika masuk ke proyek Next.js.
