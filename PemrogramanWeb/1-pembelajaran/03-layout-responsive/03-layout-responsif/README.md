# 03 — Layout Responsif

## Tujuan

- Menyusun navigasi menggunakan Flexbox.
- Menyusun kartu menggunakan CSS Grid.
- Mengubah layout berdasarkan lebar layar dengan media query.

## Tugas

Lengkapi TODO pada `style.css`. Target layout:

- ponsel: satu kolom;
- tablet: dua kolom;
- desktop: tiga kolom;
- navigasi tetap rapi tanpa overflow.

Gunakan DevTools browser untuk mencoba lebar 375 px, 768 px, dan 1280 px.
