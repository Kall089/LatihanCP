# Pembelajaran Pemrograman Web

Materi disusun bertahap: **topik → bab → latihan**. Setiap bab memiliki tujuan,
starter code, dan checklist. Kerjakan isi `1-pembelajaran/` terlebih dahulu; buka
`2-kunci-jawaban/` hanya setelah mencoba sendiri.

## Jalur belajar

1. [HTML Dasar](01-html-dasar/) — 5 bab
2. [CSS Dasar](02-css-dasar/) — 4 bab
3. [Layout Responsif](03-layout-responsive/) — 3 bab
4. [Tailwind CSS](04-tailwind-css/) — 3 bab
5. [JavaScript dan DOM](05-javascript-dom/) — 3 bab
6. [React](06-react-komponen/) — 3 bab
7. [Next.js App Router](07-nextjs-app-router/) — 3 bab
8. [Proyek Next.js + Tailwind](08-proyek-nextjs-tailwind/) — 4 tahap

## Cara menggunakan

1. Buka `README.md` pada topik, lalu mulai dari bab `01`.
2. Baca instruksi bab dan selesaikan semua komentar `TODO`.
3. Jalankan atau buka hasilnya di browser.
4. Cocokkan hasil dengan folder yang sama di `../2-kunci-jawaban/`.
5. Tulis ulang bagian yang belum dipahami tanpa menyalin semuanya sekaligus.

HTML, CSS, Tailwind CDN, dan JavaScript awal dapat dibuka langsung di browser.
Materi React dan Next.js memerlukan Node.js 20.9 atau lebih baru.
