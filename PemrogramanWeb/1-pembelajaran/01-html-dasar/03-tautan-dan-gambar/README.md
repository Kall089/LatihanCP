# 03 — Tautan dan Gambar

Lengkapi halaman galeri pada `index.html`.

## Tugas

1. Buat navigasi menuju bagian profil dan galeri pada halaman yang sama.
2. Buat tautan eksternal ke MDN yang terbuka di tab baru dengan rel yang aman.
3. Tambahkan gambar di dalam `figure`, teks alternatif, dan `figcaption`.
4. Buat tautan email pada bagian kontak.
