# Kunci Jawaban Latihan & Studi Kasus

Folder ini **terpisah** dari kunci praktikum lama (`2-kunci-jawaban/`).

```text
5-kunci-jawaban-latihan/
├── latihan-soal/01..08/JAWABAN.md     kunci 3-latihan-soal
└── studi-kasus/
    ├── 00-profil-mahasiswa/
    ├── 01-landing-page-umkm/
    ├── 02-dashboard-interaktif/
    └── 03-katalog-produk-nextjs/
```

Buka hanya setelah mengerjakan soal di `3-latihan-soal/` atau proyek di
`4-studi-kasus/`. Kunci adalah salah satu implementasi yang benar — nama,
warna, dan copy boleh berbeda selama memenuhi brief.
