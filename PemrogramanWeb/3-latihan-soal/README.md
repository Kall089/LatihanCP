# 3 — Latihan Soal

Soal penguatan konsep per modul. **Tidak ada jawaban di folder ini.** Kunci
ada di [`../5-kunci-jawaban-latihan/latihan-soal/`](../5-kunci-jawaban-latihan/latihan-soal/).

Kerjakan di kertas atau file terpisah. Buka kunci hanya setelah selesai
seluruh bagian A dan B.

## Isi tiap topik

Setiap `soal.md` berisi:

- **Bagian A — 10 soal konsep**: pilihan ganda, esai singkat, dan prediksi
  hasil kode/render.
- **Bagian B — 3 soal praktik kecil**: tulis HTML/CSS/JS/JSX sesuai brief.

## Cara memakai

1. Baca `0-materi/XX-.../teori.md` dan kerjakan praktikum dulu.
2. Tutup kunci. Kerjakan A lalu B.
3. Bandingkan dengan `../5-kunci-jawaban-latihan/latihan-soal/XX-.../JAWABAN.md`.
4. Untuk soal "apa hasil render ini", tulis alasan — bukan hanya huruf PG.

Studi kasus (proyek lebih besar) ada di [`../4-studi-kasus/`](../4-studi-kasus/),
bukan di sini.
