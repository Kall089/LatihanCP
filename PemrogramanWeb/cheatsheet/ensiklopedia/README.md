## Cara baca

1. Buka `README.md` folder materi.
2. Cari nama yang sedang dipakai (`DataFrame`, `std::vector`, `AActor`, `ArrayList`).
3. Tiap entri baru: **tipe**, **untuk apa**, **contoh implementasi**, **yang terjadi**, **biasanya digabungkan dengan**.
4. Jalankan contoh kecil, ubah satu nilai, lihat akibatnya.

Unreal di sini adalah API belajar (Actor, komponen, Blueprint). Bukan cheat atau mod gelap.

Kembali ke [daftar cheatsheet](../README.md).
