# 01 — HTML Dasar

## Tujuan

- Memahami struktur dokumen HTML.
- Menggunakan elemen semantik seperti `header`, `main`, `section`, dan `footer`.
- Membuat tautan, daftar, gambar, serta formulir sederhana.

## Tugas

Buka `index.html`, lalu selesaikan TODO dari atas ke bawah. Buat halaman profil mahasiswa dengan:

1. judul halaman yang sesuai;
2. nama dan deskripsi singkat;
3. daftar minimal tiga hal yang sedang dipelajari;
4. tautan menuju situs kampus;
5. formulir kontak berisi nama, email, pesan, dan tombol kirim.

## Menjalankan

Buka `index.html` langsung melalui browser atau gunakan Live Server.

## Checklist

- Judul tab browser sudah berubah.
- Struktur halaman memakai elemen semantik.
- Setiap input memiliki `label`.
- Gambar memiliki teks alternatif.
- Tidak ada TODO yang tersisa.
