# 05 — Formulir

Buat formulir pendaftaran kelas pada `index.html` dengan ketentuan:

- nama lengkap (`text`) dan email (`email`) wajib diisi;
- pilihan kelas menggunakan `select` dengan HTML, CSS, dan JavaScript;
- pilihan waktu menggunakan radio Pagi dan Malam dengan `name` yang sama;
- alasan belajar menggunakan `textarea`;
- checkbox persetujuan dan tombol submit;
- setiap kontrol memiliki `label` yang terhubung melalui `for` dan `id`.
