# 02 — Teks dan Daftar

## Tujuan

- Menyusun hierarki heading tanpa melompati tingkat.
- Membedakan daftar berurutan dan tidak berurutan.
- Memberi penekanan teks secara semantik.

## Tugas

Lengkapi `index.html` menjadi catatan belajar yang berisi judul utama, dua
bagian, daftar berurutan untuk langkah belajar, dan daftar tidak berurutan untuk
peralatan. Gunakan `strong` pada informasi penting dan `em` untuk penekanan.

## Checklist

- Hanya ada satu `h1`.
- Kedua bagian memakai `h2`.
- `ol` dan `ul` dipakai sesuai maknanya.
- Semua TODO selesai.
