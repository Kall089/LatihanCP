# Proyek Next.js + Tailwind: Learning Tracker

Bangun satu proyek secara bertahap. Setiap folder adalah milestone, bukan proyek
baru, sehingga hasil tahap sebelumnya dilanjutkan ke tahap berikutnya.

1. [Perencanaan data](01-perencanaan-data/)
2. [Daftar dan komponen](02-daftar-komponen/)
3. [Routing detail](03-routing-detail/)
4. [Proyek akhir](04-proyek-akhir/) — interaksi, filter, dan penyelesaian

Folder kunci jawaban berisi contoh rancangan dan potongan implementasi inti,
bukan aplikasi generator siap salin, agar proyek tetap menjadi latihan mandiri.
