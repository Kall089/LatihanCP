# Kunci Jawaban Pemrograman Web

Struktur folder ini sama dengan `1-pembelajaran/`. Buka bab yang sedang dikerjakan
dan bandingkan file satu per satu. Solusi adalah salah satu implementasi yang
benar; penamaan teks, warna, dan isi boleh berbeda selama memenuhi tujuan latihan.

## Jalur belajar

1. [HTML Dasar](01-html-dasar/) — 5 bab
2. [CSS Dasar](02-css-dasar/) — 4 bab
3. [Layout Responsif](03-layout-responsive/) — 3 bab
4. [Tailwind CSS](04-tailwind-css/) — 3 bab
5. [JavaScript dan DOM](05-javascript-dom/) — 3 bab
6. [React](06-react-komponen/) — 3 bab
7. [Next.js App Router](07-nextjs-app-router/) — 3 bab
8. [Proyek Next.js + Tailwind](08-proyek-nextjs-tailwind/) — 4 tahap

## Cara menggunakan kunci

1. Coba latihan sendiri terlebih dahulu.
2. Bandingkan bagian yang berbeda, bukan langsung menyalin seluruh file.
3. Jalankan solusi di browser untuk memahami hasilnya.
4. Kembali ke latihan dan tulis perbaikannya dengan pemahaman sendiri.

HTML, CSS, Tailwind CDN, dan JavaScript awal dapat dibuka langsung di browser.
Materi React dan Next.js memerlukan Node.js 20.9 atau lebih baru.
